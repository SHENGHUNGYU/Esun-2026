# Agent 應用操作指南

本機工作台整合官方資料、DataPack、版控策略、本地 LLM、D-Plan、持股比較、回執紀錄與結算對帳。正式操作與官方驗收結果分開；工作台不自動上傳或送出。

## 啟動

使用 Python 3.12 或 3.13，建議先在專案根目錄執行 `./scripts/start-agent.sh`；它會使用鎖定依賴、建立需要的本機通道並啟動工作台。也可分開執行 `uv sync` 與下列啟動命令。依 AGENTS.md 的設備與 GPU 限制，建立連到已驗證模型的本機 SSH 通道；模型設定在 `config/llm-local.json`，必須保持實際模型雜湊一致。

```sh
uv run esun-agent --root artifacts/live-20261024 --port 8766 --history-root artifacts/history-202604-202609
```

瀏覽器開啟 `http://127.0.0.1:8766`。要以已授權遠端下載官方公開資料，可在啟動時加 `--ssh-host`，目的地只接受 AGENTS.md 清單中的設備。設備連線資訊不隨規劃網站發布。

現有已驗證的快照位於上述本地資料目錄，屬執行產物，沒有提交 Git。全新複製專案不會附帶私人帳戶與歷史快照，必須重新匯入及取得對應交易日資料；資料不足時會阻擋。

## 每日使用

1. 匯入後台最新 DataPack；頁面顯示交易日、持股檔數與帳戶關卡。
2. 更新官方公開資料，核對決策日期與風險事件取得時間。
   在「資料與持股」填入官方行情基準日及本次交易／PCF日，再更新已支援的投信持股。表格逐檔顯示評價日；已取得不等於當日有效。
3. 啟用本地 LLM 並執行 Agent。人不指定個股或權重。
4. 檢查候選報告、本地錯誤、發布阻礙、模型理由與反證、Active Share 及預估配置。
5. 下載 D-Plan 與策略 PDF；依官方後台流程上傳、閱讀檢核、明確送出、確認歷史及逐筆當日委託。
6. 在工作台記錄操作證據。此紀錄不會觸發官方送出，也不會自動移除原始候選的發布阻礙。
   正式送出已確認後，選擇「當日委託已逐筆核對」，從官方當日委託逐行填入`股票代碼 BUY或SELL 股數`。系統檢查筆數、方向與整張股數；送出結果仍未知時不能標為確認。
7. 次日取得官方結算 DataPack 後對帳；官方庫存為決策真值。

## 資料與模型

決策 profile 包含25個交易所來源，研究 profile 維持15個。持股匯入需同時提供正規化 JSON 與雜湊一致的原始檔，來源為已核對的投信官方網域。只接受完整股票持股表，不接受只有前十大月報或僅申贖籃子。

不用FinMind即可執行。首批自動查詢adapter涵蓋野村3、安聯3、中信3、群益2檔；本輪實際連線驗證前8檔成功，中信3檔新流程HTTP403，保留阻礙、不反覆變換請求繞過。日期不符保留原始評價日，抓取失敗阻擋舊資料回退；其餘來源仍須匯入完整持股與原始證據。匿名公開頁的防偽cookie或session僅在程序記憶體中，不寫入日誌或資料庫。

命令列亦可使用`uv run esun-research --root 資料目錄 collect-etfs --reference-date YYYY-MM-DD --pcf-date YYYY-MM-DD`；遠端下載加`--ssh-host`，沿用設備白名單。單次下載失敗會回報非零結束碼；日期不符則清楚標為`date_mismatch`，候選端仍會阻擋。

LLM經本機 Ollama／SSH 通道使用，請勿把本機工作台或模型通道綁到外部介面。模型先後核對digest，JSON與引用須完整覆蓋輸入觀測。每批最多四個個股推論，最多一次修正；失敗時保留錯誤，不默默冒充模型成功。原始請求、回應、耗時及token記錄留在本地候選。

## 研究驗證頁

第五個工作區「研究驗證」與正式決策資料分開。可選1–24個已結束月份，啟動或繼續官方150檔月日行情收集；同月份成功回應共用快取，結果按範圍封存。進度顯示成功／失敗月份與日紀錄，提供報告JSON、Markdown及Parquet下載。最新2026-04至09為900／900月份、18,481筆紀錄；獨立日曆與兩市場均覆蓋124交易日。

```sh
uv run esun-research --root artifacts/history-202604-202609 collect-history --start-month 2026-04 --end-month 2026-09
```

啟動腳本可用ESUN_HISTORY_ROOT指定獨立歷史目錄。遇401／403／限流會停止該市場後續請求，稍後依來源許可再續；不換身分或代理繞過。執行中不能下載可能變動的結果，沒有活躍程序的過期進度會標中斷。

今天下載的歷史資料沒有當時首次發布／修訂版本；上市與上櫃成交統計口徑不同，上櫃張數及仟元換算也不恢復原始精度。不能拿原始未還原價量宣稱營收／估值策略已完成回測。另存的output/official-price-history-202604-202609.zip包含本次原始證據、資料及逐檔雜湊清單，沒有私人帳戶。

## 恢復與備份

同一run-id固定程式、政策、來源、資料與模型設定。使用 `uv run esun-research --root 資料目錄 resume-dplan --run-id 執行代號` 恢復封存工作；程式已改版則建立新run。備份整個資料目錄，包括objects、索引、checkpoint、候選、回執；不只備份PDF或JSON報告。

工作台重啟時核對舊工作的程序身分，仍存活的程序不重啟；已停止但缺乏完成證據的工作標示中斷。先查看紀錄再恢復，不以畫面過期推定工作已停止。

官方結算`outcome=unknown`時顯示`WAIT_OFFICIAL_OUTCOME`，即使股數暫時相同也不視為已完成對帳。

## 持續運作監測

本輪已啟動72小時目標的服務監測，進度保存在`artifacts/soak-20261026/progress.json`，每分鐘寫入一次無帳戶內容的摘要。手動啟動方式：

```sh
uv run python scripts/soak_check.py --output artifacts/soak-new --hours 72 --interval 60
```

監測只讀本機工作台與模型身分，不呼叫推論、更新資料或送出文件。斷線、工作台重啟及樣本間隔過大均重算連續健康時間；監測程序重啟也不把未觀測空檔算作通過。同一路徑以檔案鎖防止重複程序。此測試不代表完整決策流程已通過72小時壓力測試；工作台、模型通道及監測程序須持續運作。

## 交付文件

`output/pdf/ETF_strategy.pdf` 為待官方繳交的ETF策略說明；`Operator_guide.pdf` 為日常操作手冊。文件與本次候選可另打包成有雜湊清單的本地交付包。這些檔案存在不等於官方已接收，請核對後台狀態。

## 公司行動關卡

新增7項官方官網報表，與既有11項事件來源共同判斷正式停牌、終止及減資／面額換股。預告停牌期間或參考行情日至交易日跨換股／恢復日，一律阻擋未驗證股數與價格換算；退款支付日未知時，不把公告退款當可動用資金。終止日不等於最後交易日，已公告終止者依內部政策先排除新買。合併與企業分割尚未完整覆蓋。

更新來源後需要新建候選；舊run固定其原始來源、政策與程式hash。每項觀測最多10個來源；風險證據分組後由個股推論引用，不會因增加端點而截斷引用。

## 官方流程進度與版本

在「繳交紀錄與對帳」直接選擇候選，即可查看五階段進度並下載JSON摘要。同隊同交易日改送別版、重送同版或產生未知結果後，舊委託確認會失效；回官方後台重新查證後再記錄。策略PDF正式繳交紀錄綁定目前下載文件的hash，PDF改版後不自動沿用。

保存紀錄前核對階段與版本；有附件仍是操作人員提供的證據，不是官方接口直接認證。次日對帳保存原始DataPack並重新計算，未知結果維持等待，股數一致不代表費用或合規通過。可下載原附件及摘要作備份；完整備份仍須包含資料目錄。詳見planning/30-submission-evidence.md。
