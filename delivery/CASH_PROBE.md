# 有限現金試探與品質修復比較

目的為在限制內追求短期淨值成長，將成本及風險作為比較因素，並保留續抱、防守、漸進與換股方案；不以最低費用或最低波動自動決定勝出。

## 新操作 cash_probe

- 只買進，以既有可動用現金支應；本方案不賣原持股。
- 每日現金支出（含費用）最多 2% NAV、最多兩檔，每檔增加不超過 1% NAV；保留至少 18% 參考 NAV 現金，且遵守 Agent 指定的更高保留目標。
- 最多 30 檔、整張、不得使用應收款或應收配股。原有單股、產業、現金、事件、費稅、換手與價格壓力關卡繼續執行。
- 通過條件：正營收年增、二十日相對股票池為正、最近一日或三日報酬為正，以及三日外資／投信至少一方淨買。這是試探資格，非盈利品質、底部或預期收益認證。
- 依 Agent 提出的因子與權重排名，程式選擇可行股數；沒有指定任何個股。沒有適合標的或現金不足，可產生零委託。

## 研究與審查

完整股票池資料存在且已有官方結算持股時，Agent 必須評估 cash_probe，再與其他不同假說、續抱及同因子漸進對照。選擇權仍屬 Agent，並不強制增加風險或執行交易。

市場狀態由股票池上漲家數、站五日均價家數及三日正報酬家數描述為 unknown／stressed／mixed／recovering。它是待驗證的研究啟發式，不是官方市場指數、底部確認或自動交易訊號。共同市場報酬的扣除不會改變同窗口截面動能排序。

每個現金方案另有 deployment 審查，保留實際買進的資格數值、來源、動用資金及調整前後風險。完整資料與判斷封存；選擇階段只保留必要摘要。研究步數上限改為 24，模型上下文及修正保留不變。
