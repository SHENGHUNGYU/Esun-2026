# 研究上下文容量修復

來源：`daily-2026-11-05-e4e28224b36b`；行情基準 2026-11-04，決策日 2026-11-05。

## 根因

研究、方案比較與 14 個必要審查均已完成。第一次 select 因交易理由沒有點名實際交易個股，被 `hold_comparison_requires_an_actual_traded_security` 退回。下一輪再加入錯誤回饋與方案摘要，舊裁切後由 25,347 增至 25,982 bytes，超過內部 25,600 bytes 門檻，於模型呼叫前停止。

這次不是模型服務中斷或 GPU 記憶體不足；是通用研究提示重播過多重複資料，且沒有對修正回饋保留獨立容量。

## 架構調整

- 選擇階段使用專屬 `SELECTION_SYSTEM` 與 `selection-v2` 輸入，不再重播 inspect 目錄、歷史自由文字、完整研究假說及先前工具結果。
- 保留完整官方帳戶、全部候選／最新引用、精確現金／成本／換手、全部硬錯誤及每個失敗壓力情境；不能因裁切把不可行方案變可行。
- 全部必要審查的 ID、verdict、features 保留；詳細論述仍保存在不可變 review packet 與 D-Plan 審查證據。選擇角色不能宣稱重新讀取未展示的文字。
- 因子及篩選規則去重為共用字典，候選使用欄位陣列；交易證據仍可回源。只有提示中的分數／因子觀測顯示到八位有效數字，帳戶、成本及實際計算精度不變。
- 只保留最新錯誤代碼與工具 ID，不把所選方案的完整摘要再附一遍。
- 額外預留 1,024 bytes 給有界輸出修正；每次實際呼叫仍檢查訊息容量。模型視窗、輸出額度與正式策略硬限制不放寬。
- select 輸出 schema 僅含該階段需要的選擇及比較欄位，不再附上未使用的個股目錄、提案及審查 schema；每項比較限制為簡潔理由。

真實封存輸入重播：新提示約 13,066 bytes，可用預算 24,576 bytes，另外保留修正額度。這是內部保守 UTF-8 預算，不宣稱等於模型 tokenizer 的精確數量。

## 恢復與證據

允許從 `agent_context_budget_exceeded` 或 `agent_research_budget_exhausted` 的未選定研究，另開新 run 接續。保留原 cutoff、資料快照、帳戶、策略參數、trace 與已核對審查；不能靜默改用基線。來源 request／research hash 與新舊程式 hash 另存 provenance。

跨序列化的 evaluation map 依已驗證原始 review packet 還原順序，避免 JSON key 排序導致相同證據被誤判改變而重做審查。

回歸包含：實際超界回饋案例、30 檔持股與審查、11 個可行比較／八因子規則、19 個含失敗情境的候選、所有風險結果保留、修正預留、恢復時只呼叫 select 且不重做已完成審查。

容量檢查仍會阻擋超出支援規格的輸入，不以任意刪除帳戶或安全資訊換取產出。本輪修復驗證的是上述正常容量邊界與已知失敗，不代表對任意模型／任意外部資料長度的無條件保證。
