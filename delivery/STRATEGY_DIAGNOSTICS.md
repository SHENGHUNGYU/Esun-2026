# 選股排除、資產橋接與漸進非等權配置

工作台的「策略診斷與實驗」可選擇既有執行版本，使用已取得資料建立新分析。沒有下載、模型推論或正式交易副作用。分析會保存原來源、資料截止時間、程式版本、策略、參數及原始快照，並驗證輸出雜湊。

## 選股排除診斷

每次策略 evaluate 都記錄完整官方股票池，分為行情缺漏、前置排除、因子缺漏、篩選未過與已進入評分。另列排名、實際持有、目標持有與來源參照。新候選輸出 selection-diagnostics.json，LLM 可以看見缺值數量。

排名資格與持股不同：資料缺漏可以讓股票失去當日評分資格，續抱政策仍可能保留該股票。不能把缺值解釋成看空。已排名但未配置可能涉及產業、整張及續抱限制，報告不將它一律歸因為排名不夠好。

## 同期資產變化

以同隊兩份官方結算及同日期官方收盤價核對：

總資產變化 = 原股數 × 收盤價變化 + 股數變化 × 期末收盤價 + 現金變化 + 應收權益市值變化 + 未解釋差額。

已出清股票不在新 DataPack 時，需要額外的同日收盤價才能完整拆解。若缺價則明列差額；不填零。快照可能不相鄰，日期明列。

這是非還原價格的會計橋接，並非交易績效因果歸因。公司行動可能同時影響價格及股數。沒有成交明細時，不把現金變化當成已實現損益，亦不分離費稅、滑價、外部資金流或個股交易獲利。尚未提供同期指數／市值／產業基準歸因。

## 漸進配置

新增策略 mode=gradual，可由 LLM 自主提出與選擇。原有 rebalance、hold 等模式保留。

- 固定官方現有可交易股票籃子，不新買或出清名稱。
- 缺少本策略因子的股票維持原股數；不填補因子值。
- 在資料完整的既有部位間，以原投入市值分配 equal 或 rank_tilt 目標。
- 只有目標偏離免調整區間、買方分數高於賣方且訊號差通過門檻時，才做成對減碼／加碼。
- 買進金額由減碼淨收入支應，不動用原現金。費用與整張取整可能略提高殘餘現金。
- 預設最多兩組配對，每個代碼每日最多調整一次，每檔調整名目金額最多為 NAV 的 0.5%。不強制用完額度。
- 共用買賣合計 20% NAV、費稅 6bps、最小交易 0.3% NAV、權重免調整 0.3 個百分點、訊號差 0.15 的工程控制。這些不是經回測最佳化的參數。
- 繼續檢查現金、單股／產業限制、交易事件與九種價格壓力情境。沒有漸進模式的預算豁免。
- 對外輸出仍為官方 ADD／TRIM 及 BUY／SELL 股數；未變動股票列 no_trade_decisions。

## 實驗與正式選擇分開

離線報告比較 HOLD、FIXED_EQUAL、FIXED_RANK_TILT，固定同一股票籃子與初始現金。因子方案若完全沒有可評分股票，會明列改用同一來源先前已研究、覆蓋較完整的替代方案；兩個配置實驗共用該方案。這是資料可用性對照，不能稱為原策略改權重後的績效改善。

估算費用使用參考收盤價，正式成交均價尚未知。報告不呼叫模型、不產生 D-Plan、不表示 Agent 已採用。下一次新候選由 LLM 與續抱及其他方案比較後選擇，必須解釋交易必要性；不能以「續抱缺乏因子驅動」取代新證據。

命令列：

```sh
.venv/bin/python -m esun_research.cli --root artifacts/llm-agent-20261027 analyze-strategy --source-run <既有執行版本> --refresh
```

`--refresh` 只重新選取本地已取得的資料；不下載資料，也不修改原執行版本。產物在執行根目錄的 strategy-analysis/ 下。
