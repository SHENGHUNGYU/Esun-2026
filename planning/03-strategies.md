## 推薦主題與主線

研究主題暫定「台灣品質成長與趨勢輪動」：在官方 150 檔中，結合營收／獲利品質、價格趨勢、法人籌碼與事件風險，保留跨產業配置能力。主題是研究候選，正式 ETF 名稱（20 字內）、主題（50 字內）、理念（100–300 字）需由最終 Agent 依研究結果生成，檢查字數並留存產出軌跡。[格式](../docs/玉山挑戰賽%20ETF%20投資策略說明.docx)；[主題一致要求](../docs/玉山挑戰賽%20ETF%20投資策略範例.pdf)

排序分數→選 25 檔→限制配置→整張離散化→再驗證，是所有策略共用通道。25 檔是內部預設，可合法落在 20–30；不預先人工指定持股。常態現金 8–15%、防禦 18–22%、2330≤20%、其他≤8% 是待測安全緩衝，不是回測結論。

## 金融特徵與數學方法

1. 價格動能：20/60/120 日相對報酬、產業相對強弱；短期反轉作交易成本與追高抑制。調整後價格僅研究用，成交與記帳使用原始價。
2. 基本面：營收 YoY、3 個月加速度、毛利率／ROE、現金流、估值分位。依公告可用時間入模；財報季末不等於發布日。
3. 籌碼：外資／投信買賣、量能異常與持續性。數量與金額單位統一，標準化僅 fit 訓練期。
4. 跨市場：已收盤 SOX／Nasdaq、TSM ADR、匯率、台指夜盤作 regime；美股只能作訊號，不能在本競賽買入。以 IANA 時區轉換，跨 11 月美國 DST 不能固定假設台灣 04:00 收盤。
5. 風險：EWMA／收縮協方差、產業曝險、CVaR、流動性容量。HMM／change-point 可作 regime 挑戰者，不能用全資料平滑狀態造成未來洩漏。
6. 抗過擬合：特徵群消融、block bootstrap、同策略短窗分布、交易成本敏感度。conformal 區間僅在其校準假設下解讀，市場轉態不保證覆蓋。

配置目標可為 `max μᵀw − λ wᵀΣw − γ Σ|w−w_prev| − η CVaR`，加上法定白名單、現金、持股數、上限、主題與 Active Share 檢查。先候選篩選再連續優化、取整後重算；Active Share 下限及持股數非一般凸約束，不宣稱丟給 QP 即可解。先用可重現啟發式選股＋候選交換；必要時再導入混合整數求解並設 timeout／fallback。

換倉採分數滯後門檻、排名緩衝和換手懲罰，避免每日全換。費稅來回約 0.585%（價位相同時，未計其他成本）；微小 alpha 不值得頻繁交易。停損只能在下一次盤前決策產生，以當日均價成交，不能回測成盤中觸價即成交。

## LLM 與 Agent 的定位

LLM 做來源選擇、事件結構化、相反證據、主題一致性與可讀推論；數學工具做計算、排序和配置。Agent 必須真正利用觀察選擇政策或風險狀態，保留這一步的機器可讀決策；不能事後為人工選股補理由。先單一可恢復工作流，避免多個 LLM 自由辯論造成不可控延遲。

供應商選擇採同一組 100 則中文金融事件測試：格式成功率、數值正確率、引用正確率、延遲 P95、每日成本。主模型與備援模型皆鎖定確切版本／權重 hash；本文件不宣稱任何未測模型是最佳。大型本地模型只有比小模型或 API 多出可測價值才投入。

## JEV 的定位與兩個產品

使用者指定的是 AutoTrust JEV-27B 或 TypeSafe Jev，與 JEPA 無關。AutoTrust 模型卡描述其為獨立開放權重學生模型，提供 typed decision 與文字生成路徑；不隸屬 TypeSafe。其測試數字由作者自報，不能當作台股資料的驗證結果。[JEV-27B 模型卡](https://huggingface.co/autotrust/JEV-27B)

TypeSafe Jev 是託管決策服務，介面以固定選項、評分與真假判斷為核心。接入時核對官方模型版本與 schema，不使用第三方同名服務冒充原廠。[TypeSafe 官方介紹](https://typesafe.ai/blog/introducing-system-one-models-and-jev)、[官方快速入門](https://docs.typesafe.ai/introduction/quickstart)

**本專案提出的用法**：JEV 回答「證據是否支持既定說法」「哪個市場狀態最合理」「下一步需要哪個工具」；一般 LLM 產生中文推論與反方證據；確定性程式執行數值合規。JEV 的選項機率不是股票上漲機率，更不能直接轉成投資權重。型別正確也可能語意錯誤，不能取代白名單、現金及股數檢查。

E06 評測：至少 200 則中文金融案例，120 開發／校準、80 封存驗證；保留來源和標註理由、分歧裁決。含否定句、金額單位、重複新聞、矛盾消息、缺證據、提示注入。選項亂序重測、繁簡中／英語轉述測試，分任務報 macro-F1、Brier、ECE、拒答率、錯誤高信心率及成本／延遲。測試集小，須報 bootstrap 區間，不用 ECE 小數點精度假裝穩定。採用門檻暫定：證據支持分類 macro-F1≥0.85、高信心錯判≤5%、option shuffle 一致率≥95%，且不劣於一般 LLM 基線；這些是內部提案而非已達成結果。

D3–4 優先 API 可行性與 30 例 smoke test；D5–6 評測完整集；D7–8 再評估自架價值。若 API 未獲存取，本地適配最多 1 人日；仍卡住即改用一般 LLM 的結構化輸出，交付 JEV 研究報告與接口，不讓它阻塞 D14。

## RL 最小實驗與標籤定義

兩週僅研究 contextual bandit 或小型 PPO 配比控制器：動作選擇「品質優先／動能優先／防禦」三組預定配比，由同一 allocator 完成選股與合規。狀態僅含當時可得的 regime、波動、現金及近期回撤。reward 用成本後 `Δlog(NAV) − λ×新增回撤 − η×違規指標`；費稅已在 NAV 扣除，避免重複計成本。動作經 constraint projection，無法修復就採合法基線；不可只靠 reward 懲罰期待學會硬限制。驗證和測試期凍結 policy，至少 3 seeds、同切分比較固定配比，失敗或時間不足就停止。

ML 主標籤可定為 `close(t+h)/avg_price(t)−1` 再減同口徑股票池基準報酬（h＝5／10／20 交易日）；模型決策在 t 開盤前，t 的成交均價僅出現在未來 label／執行器，不可在 features。這是持有至收盤的研究標籤；最終實際賣出仍按官方當日均價，採用結果以完整模擬器為準。也可測兩端均價標籤，但不同定義要分實驗版號，不能混合比較。

TypeSafe 官方目前模型列表將 stable alias 指向 `jev-1.13.0`，且明示英文表現優於其他語言；因此本案固定版本並獨立驗證繁體中文。[官方模型列表](https://docs.typesafe.ai/models) 官方已知弱點還包含精確計數、日期比較、對抗內容和選項次序，所以財務計算與時間窗判定一律交給程式，JEV 只做語意判斷。[已知弱點](https://docs.typesafe.ai/model-jaggedness/jev-1.13)
