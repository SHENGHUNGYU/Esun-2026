## 已完成的可執行流程

```text
官方 DataPack 匯入 → 日期／帳戶／來源關卡 → 交易事件篩選
→ 自主因子排名與分散配置 → 官方整張股數換算
→ 本地 LLM 市場推論、個股理由與反證 → 引用／數值／委託驗證

→ 操作證據紀錄 → 官方次日 DataPack 股數對帳
```

工作台提供今日工作、候選與報告、資料與持股、繳交紀錄與對帳四個區域。資料及帳戶只留在本機；工作台不自動上傳或正式送出。官方後台操作證據以獨立紀錄保存，不修改原始候選的驗證結果。

## 真實 LLM 驗收

- 已透過僅綁定本機的 SSH 通道連到既有 Ollama，實際使用既有量化模型；沒有使用付費 API，也沒有宣稱 JEV／RL／ML 已啟用。
- 設定固定模型完整 digest，每次推論前後核對身分。D-Plan metadata 記錄模型版本、雜湊識別及實際回報的 token 用量。
- 一次完整工作台執行，完成市場背景與25個個股理由／反證，共9次有請求與回應證據的呼叫（含一次修正），模型時間合計約190秒。資料只含公開觀測與規則結論，不傳送官方帳戶或金鑰。
- LLM 不可改動個股、權重、股數與硬限制。文字檢查包括schema、完整引用覆蓋、數字及保證獲利過濾；這些檢查不等於已證明所有推論語意正確，原始文字與反證仍可檢閱。
- 模型驗證失敗會阻擋啟用模型的候選，不默默當作已使用模型。每批最多四檔、最多一次修正；模型工具呼叫與未完整輸出均拒絕。
