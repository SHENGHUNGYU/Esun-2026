## 已完成的可執行流程

```text
官方 DataPack 匯入 → 日期／帳戶／來源關卡 → 交易事件篩選
→ 自主因子排名與分散配置 → 官方整張股數換算
→ 本地 LLM 市場推論、個股理由與反證 → 引用／數值／委託驗證
→ Active Share 雙口徑比較 → D-Plan、報告、PDF 與交付包
→ 操作證據紀錄 → 官方次日 DataPack 股數對帳
```

工作台提供今日工作、候選與報告、資料與持股、繳交紀錄與對帳及研究驗證五個區域。資料及帳戶只留在本機；工作台不自動上傳或正式送出。官方後台操作證據以獨立紀錄保存，不修改原始候選的驗證結果。
