## S01 同期基準、續抱反事實與成本後交易歸因

狀態：待開始。優先序：P0。

- [ ] 接入可核對的台股含息基準，記錄來源、幣別、交易日、發布時間、修訂及使用權；價格指數不得冒充含息報酬。
- [ ] 每個決策日封存「維持昨日實際股數不動」組合，與實際執行策略使用同期間、同資金與公司行動口徑比較。
- [ ] 以實際送出版本、官方結算及可核對成交證據關聯交易；候選不當成交，股數吻合不當正式送出證明。
- [ ] 拆解每日與累計價格效果、交易費稅、股息／配股及現金配置，呈現個股貢獻與未解釋差額；估計和已核對結果分列。
- [ ] 回答「今日交易相較續抱，成本後多賺或少賺多少」，保留未知、缺資料與未能重建的日期，不回填假精確數字。

驗收：同窗實際策略／含息基準／續抱比較可重建；未交易日及部分成交案例合理；不把選股貢獻與現金效果混為一談；證據不足顯示覆蓋率與殘差。比較結果是已實現的反事實估計，不自動證明未來策略優勢。

## S02 時間序列與推理主張的證據驗證

- [ ] 「持續淨買入」需多交易日序列；「轉強」需前後比較；「曲線陡峭化」需斜率變化，不能只由長端高於短端推出。
- [ ] 區分期貨淨空與現貨看空、法人流量與持股比例、營收成長與獲利改善；無相應證據只能列為未知或條件式假說。
- [ ] 引用須覆蓋主張及其反證涉及的個股、期間、欄位與來源，不能只驗證引用 ID 存在。
- [ ] 反證角色須提出矛盾、拒絕無法支持的主張或要求補資料；不得僅換句話重述專員結論。
