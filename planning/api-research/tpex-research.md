# TPEx OpenAPI 端點盤點與參賽適用性

研究日期：2026-10-09。此檔是資料能力研究，不是 225 個端點皆已接通的驗收結果。優先序與 Dxx 關聯是依本專案決策資料地圖作出的研究判斷，官方分類保留在 tags。

## 取得流程與完整性

先讀取 [TPEx 官方 Swagger 入口](https://www.tpex.org.tw/openapi/) 的 HTML，入口明確指定 [swagger.json](https://www.tpex.org.tw/openapi/swagger.json)，再下載規格；沒有猜測端點名稱。規格為 OpenAPI 3.0.0，info.version 為 1.0.0，servers 明列 `https://www.tpex.org.tw/openapi/v1`。此次快照有 **225 個 path、225 個 GET operation、225 個 schema**。[來源：官方規格](https://www.tpex.org.tw/openapi/swagger.json)

原始入口、HTTP headers、Swagger、四個代表端點回應封存在 `planning/api-research/tpex/`；所有 operation 的方法、URL、官方 summary／description、tags、參數、response 欄位名稱與型別、媒體型態、安全設定、優先序、用途及 Dxx 關聯在 `planning/api-research/tpex-operations.json`。`extract_operations.py` 可從相同規格重建此清單；規格雜湊與統計在 `tpex/metadata.json`。

## 全域限制與已驗證範圍

- 所有 225 operation **未宣告 parameters**；沒有宣告日期、證券代號、分頁、排序或限制筆數參數。這表示規格沒有文件化這些能力，不能保證任意歷史查詢，也不能推論伺服器絕對拒絕所有 query。勿自行加上 `date` 或 `stockNo` 並假設已生效。[來源：官方規格](https://www.tpex.org.tw/openapi/swagger.json)
- 沒有全域／operation `security` 或 `components.securitySchemes`。四個代表端點沒有提供 key 或登入憑證也回傳 HTTP 200；未對全部端點實測。HTTP CORS 允許 `api_key`／Authorization header 不等於此服務要求 key；同理 CORS 宣告 POST 也不代表 Swagger 的 GET operation 可以改用 POST。[來源：官方規格](https://www.tpex.org.tw/openapi/swagger.json)
- 每個 200 回應均文件化 `application/json` 與 `text/csv`。本次僅測 JSON，沒有驗證 CSV 的格式與字元編碼。規格 response schema 宣告 object，四個實際 JSON 回應都是 array of objects；adapter 需兼容實際根結構並檢查欄位。[來源：官方規格](https://www.tpex.org.tw/openapi/swagger.json)
- 3,254 個 schema 欄位中 3,250 個宣告 string，只有 `/tpex_margin_trading_lend` 的四個標借張數／單價欄位宣告 number；不能把一般字串欄位直接當 numeric 運算。須處理逗號、空值、特殊符號與日期格式。schema 的名稱或描述不一定給出金額／股數／千元單位，逐表核對，不能跨表推定。[來源：官方規格](https://www.tpex.org.tw/openapi/swagger.json)
- OpenAPI 未給服務配額、SLA、每張表固定更新時刻或保存期間。行情官方政府資料集明列每日收盤後、每 1 日更新、免費及政府資料開放授權，但 [市場現況資料集](https://data.gov.tw/dataset/11369) 頻率標為不定期更新，不能以行情的頻率推及 225 張表。[來源：收盤行情](https://data.gov.tw/dataset/11371)、[股票行情](https://data.gov.tw/dataset/11370)、[融資融券](https://data.gov.tw/dataset/11387)
- 本次 Swagger HTTP `Last-Modified` 為 2026-07-01 07:53:53 GMT，這是規格檔案的版本時間；資料 HTTP Last-Modified 是檔案更新時間，皆不能當各筆公司的首次公告時間。必須另保存 `published_at / first_seen_at / fetched_at / available_at / content_hash`。
- web 工具讀 TPEx 入口與條款曾遇 403，普通唯讀 curl 取得入口與 Swagger HTTP 200；此差異記錄為來源可達性現象，沒有繞過警告、登入或驗證機制。

## 兩週應先接的集合與缺口

1. **帳本與可交易性**：`tpex_mainboard_daily_close_quotes`／`tpex_mainboard_quotes`、基本資料、暫停恢復、變更交易、處置、除權息預告與結果。daily_close_quotes 多了 Average 與 NextReferencePrice；Average 仍需用成交金額／股數交叉驗證是否吻合競賽公式，不能忽略單位與市場交易範圍。官方資料集說前者股票／ETF／ETN，後者另含權證，必須過濾固定宇宙。[股票行情](https://data.gov.tw/dataset/11370)、[收盤行情](https://data.gov.tw/dataset/11371)
2. **策略基線**：月營收、一般業財報／損益／資產負債、估值、三大法人逐股交易、櫃買指數與報酬指數、重大訊息；金融等產業用對應財報表。Beta、MACD、RSI、動能與協方差需由適當歷史價量與基準衍生，並非已有端點直接提供這些完整模型指標。
3. **次要增量**：外資持股、融資融券借券、內部人質押與轉讓、產業營收、治理與裁罰、風格指數等；先補時點與歷史，才可用於 ML。
4. **本規格未提供的關鍵資料**：指定 30 ETF 每日實際前 15 大持股、完整現金流量表、集保股權級距、完整多年 PIT 財報與公告版本、完整財經媒體新聞、海外行情／總體資料及競賽提交回執。指數成分不是基金持股；資產負債表的現金餘額不是 CFO／FCF；券商營業金額／熱門排行不是每檔完整分點買賣資料。這些仍需官方基金網站、MOPS／TEJ、TDCC、新聞來源及競賽系統。
5. **歷史補齊路徑**：先逐日不可變快照，再評估 TEJ 既有權限、官方歷史查詢或 TPEx E-Data Shop 已訂閱資料。官方另有 [盤後 API 文件入口](https://eshop.tpex.org.tw/en/product/list/31)，這與公開 OpenAPI 是不同服務；不能以文件商品 NT$0 推論所有盤後產品／多年歷史免費，也沒有本次付費訂閱授權。
